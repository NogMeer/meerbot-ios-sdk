## [0.1.0] — 2026-08-11

Первая работоспособная версия: чат со стримингом, восстановление после обрыва, регистрация пуш-токена.

### Добавлено
- `MeerBot.shared.configure(apiKey:pushApiKey:origin:baseURL:)` — настройка SDK.
- `MeerBot.shared.chatView(title:primaryColor:onClose:)` — готовый SwiftUI-экран чата.
- `MeerBot.shared.chatController()` — доступ к состоянию для собственного UI.
- `MeerBot.shared.preconnect()` — прогрев сессии перед показом экрана.
- `setPushToken(_:)` / `handlePush(_:)` — регистрация APNs-токена и переход в диалог из пуша.
- Потоковый разбор SSE, обновление 15-минутного JWT с одним повтором, догон истории после обрыва.
- 40 тестов: разбор SSE, обновление токена, поведение при обрыве сети, форма запросов.

### Исправлено
- Пакет не собирался вовсе: тест-таргет был объявлен без каталога `Tests/`.
- `TextField(axis:)` требует iOS 16 при заявленном минимуме iOS 15 — добавлена ветка для iOS 15.
- Разбор SSE терял текст, если UTF-8 символ разрывался границей сетевого чанка (кириллица — 2 байта).
- Тело запроса чата отправлялось полем `content`; бэкенд принимает `message`.
- `chatView()` возвращал заглушку вместо реального экрана; `ChatView` отвечал фиксированной строкой.
- `setPushToken` / `handlePush` печатали в консоль вместо работы с API.

### Известные ограничения
- Чат работает по ключу headless-виджета, пуши — по ключу мобильного приложения (два ключа).
- Доставка пушей на бэкенде — заглушка; аттестация устройства не реализована.
- Нет вложений и verified identity.
