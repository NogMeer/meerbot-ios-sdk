# Демо-приложение

Минимальный пример на двух экранах: готовый `chatView()` и собственный интерфейс поверх
`ChatController`.

Здесь лежат только исходники — без `.xcodeproj`. Так сделано намеренно: сгенерированный
проектный файл пришлось бы держать в актуальном состоянии под каждую версию Xcode, а пользы
от него на четыре файла нет.

## Запуск (3 минуты)

1. Xcode → **File → New → Project → iOS → App**, имя `MeerBotDemo`, интерфейс **SwiftUI**.
2. Удалите созданные `MeerBotDemoApp.swift` и `ContentView.swift`, перетащите в проект файлы
   из `MeerBotDemo/` этой папки.
3. **File → Add Package Dependencies…** → `https://github.com/NogMeer/meerbot-ios-sdk` →
   правило версии **Up to Next Minor** от `0.1.0`.

   Для проверки локальных правок вместо URL добавьте пакет из папки: **Add Local…** →
   выбрать `mobile-sdk-ios/`.
4. В `Info.plist` добавьте строковый ключ `MeerBotApiKey` со значением `pk_live_…` вашего
   headless-виджета (кабинет → Бот → Каналы → Виджеты).
5. В настройках канала в кабинете добавьте в «Разрешённые домены» строку
   `https://<bundle identifier проекта>` — например `https://com.example.MeerBotDemo`.
6. Запустите на симуляторе.

Без шага 5 handshake вернёт `key_invalid`: публичный ключ привязан к домену, а SDK шлёт
`Origin`, собранный из bundle identifier.

## Что смотреть

- **Готовый экран** — сколько кода нужно на полноценный чат (ответ строкой в `App.init` плюс
  `chatView()` в `sheet`).
- **Свой UI** — какие поля состояния доступны: лента, `streaming`, `failed`, `mode`,
  `connectionError` и повтор отправки.
- Включите авиарежим во время ответа: пришедший текст останется, появится баннер с «Повторить».
